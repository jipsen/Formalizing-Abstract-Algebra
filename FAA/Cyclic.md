**Def ([`cyclicSubgroup`](Cyclic.lean#L32))**

Judson 4.1.3: the cyclic subgroup generated by $a$ is $\langle a \rangle = \{a^k \mid k \in \mathbb{Z}\}$ — `Subgroup.zpowers`.

**Theorem ([`mem_cyclicSubgroup`](Cyclic.lean#L35))**

Judson 4.1.3: $x \in \langle a \rangle$ if and only if $x = a^k$ for some $k \in \mathbb{Z}$ — `Subgroup.mem_zpowers_iff`.

**Theorem ([`commutative_of_isCyclic`](Cyclic.lean#L39))**

Judson 4.1.9: a cyclic group is abelian.

*Proof.*

> Ass: $G$ cyclic with generator $g$
> Have: $x = g^m$ and $y = g^n$ for some $m, n \in \mathbb{Z}$ (`IsCyclic.exists_generator`, `mem_zpowers_iff`)
> Have: $xy = g^m g^n = g^{m+n} = g^{n+m} = g^n g^m = yx$
> QED

**Theorem ([`isCyclic_subgroup`](Cyclic.lean#L46))**

Judson 4.1.10: every subgroup of a cyclic group is cyclic — the Mathlib `Subgroup.isCyclic` instance.

**Theorem ([`orderOf_dvd_of_pow_eq_one'`](Cyclic.lean#L49))**

Judson 4.1.11: if $a^n = 1$ then $|a|$ divides $n$ — `orderOf_dvd_of_pow_eq_one`.

**Theorem ([`orderOf_pow'`](Cyclic.lean#L53))**

Judson 4.1.13: for a finite group, $|a^k| = |a| / \gcd(|a|, k)$ — `orderOf_pow`.

**Theorem ([`zmod_isAddCyclic`](Cyclic.lean#L58))**

Judson 4.1.14: $\mathbb{Z}_n$ is cyclic under addition — the Mathlib `ZMod.instIsAddCyclic` instance.

**Theorem ([`addOrderOf_zmod_eq_iff_coprime`](Cyclic.lean#L61))**

Judson 4.1.14: $(k : \mathbb{Z}_n)$ has additive order $n$ — i.e. generates $\mathbb{Z}_n$ — if and only if $\gcd(k, n) = 1$.

*Proof.*

> Have: $|k| = n / \gcd(n, k)$ in $\mathbb{Z}_n$ (`ZMod.addOrderOf_coe`)
> Show: $n / \gcd(n, k) = n \iff \gcd(n, k) = 1$
> Ass: $n / \gcd(n, k) = n$
> Have: $n \cdot \gcd(n, k) = (n / \gcd(n, k)) \cdot \gcd(n, k) = n$, since $\gcd(n, k) \mid n$
> Have: $\gcd(n, k) = 1$ by left cancellation of the nonzero factor $n$
> Conversely, $\gcd(n, k) = 1$ gives $n / 1 = n$
> QED
